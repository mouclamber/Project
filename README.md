# Anatomy Route

Простая консольная программа на C#: находит кратчайший путь препарата
по кровеносной системе от места инъекции до нужного органа.

## Что делает

- Строит граф кровеносной системы: **органы = вершины**, **сосуды = рёбра**.
- Вес ребра — время прохождения крови (в секундах).
- Ищет путь с минимальным временем алгоритмом Дейкстры.
- Печатает маршрут: через какие органы идёт препарат и сколько это занимает.

## Как запустить

Нужен **.NET SDK 8.0** или новее.

```bash
dotnet run
```

## Режимы запуска

| Команда | Что произойдёт |
|---|---|
| `dotnet run` | Тесты + маршрут |
| `dotnet run -- test` | Только тесты + маршрут |
| `dotnet run -- demo` | Только маршрут, без тестов |

## Файлы проекта

```
ConsoleApp4.csproj   ← настройки проекта
Program.cs           ← граф, алгоритм, запуск
Tests.cs             ← тесты, проверяющие Program.cs
```

## Как поменять маршрут

В `Program.cs` в `Main` найдите:

```csharp
RunDemo(1, 11);
```

Числа — это номера вершин:
- первый — откуда (start),
- второй — куда (target).

Список вершин:

| № | Орган |
|---|---|
| 0 | Вена руки (место инъекции) |
| 1 | Правое предсердие |
| 2 | Правый желудочек |
| 3 | Лёгкие |
| 4 | Левое предсердие |
| 5 | Левый желудочек |
| 6 | Аорта |
| 7 | Сонная артерия |
| 8 | Головной мозг |
| 9 | Печень |
| 10 | Почки |
| 11 | Опухоль в мозге |

Например, `RunDemo(0, 9)` — путь от вены руки до печени.

## Как добавить новый сосуд

В методе `RunDemo` добавьте строку:

```csharp
AddEdge(6, 9, 2, "Печёночная артерия");
```

Формат: `AddEdge(откуда, куда, время_в_секундах, "название")`.

## Тесты

Файл `Tests.cs` содержит 7 проверок:
- кратчайшее расстояние до цели;
- расстояние до старта = 0;
- правильное восстановление пути;
- недостижимая вершина = бесконечность;
- обход короче прямого пути;
- `start == end`;
- ветвление (аорта → печень и почки).

Запуск:

```bash
dotnet run -- test
```

## Ограничения

- Веса только положительные (Дейкстра не работает с отрицательными).
- Граф направленный: кровь течёт в одну сторону.
- Модель упрощённая: только крупные сосуды.
